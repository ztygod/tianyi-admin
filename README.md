## tianyi-admin
自己第一个小项目，可以看作是一个阶段性成果，主要是利用vue2全家桶完成的一个后端管理项目。
完整技术栈如下：`Vue2` + `vuex` + `vue-router` + `element-ui` + `echarts` + `less` + `mockjs`

## 功能

1. 前端通过动态路由，完成登录鉴权✨
2. 利用mock.js模拟后端，实现前后端数据互通✨
3. 封装axios实现拦截器，向虚拟后端请求用户菜单数据✨
4. 通过echarts与后端数据，实现可视化图表✨
5. 建立用户信息列表，实现了用户数据的增删改查✨
